# The Shamani Hub — Raj Shamani Fan Website

A beginner-friendly 2-page creator website built with:
- HTML
- CSS
- JavaScript
- Netlify Forms for the backend form

## Pages
1. `index.html` — Home
2. `join.html` — Community signup form

## How to run locally
Just double-click `index.html`, or use VS Code + Live Server.

## How to deploy
1. Create a free account at Netlify.
2. Drag the whole project folder into Netlify's deploy area.
3. Wait for deployment.
4. Open your live website.
5. Go to `join.html` and submit a test form.
6. In Netlify, open your site dashboard → Forms to see submissions.

## Important
This is a fan-made project for a development challenge. It is not an official Raj Shamani website.
The hero image is intentionally represented by a stylized placeholder, so you can replace it with a properly licensed image if desired.
